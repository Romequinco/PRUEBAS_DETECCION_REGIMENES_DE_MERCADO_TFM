# Registro de eliminaciones (unificación ADR-004)

Todo archivo o bloque grande de código que desaparezca en la unificación tiene aquí su fila.
Mover un archivo (`git mv`) no es eliminarlo y no se registra.

"Dónde queda": tag `capa1-final` (Capa 1 congelada), tag `v2-pre-unificacion` (código v2
previo a la unificación) y/o la nueva ubicación en `src/regimenes/`.
