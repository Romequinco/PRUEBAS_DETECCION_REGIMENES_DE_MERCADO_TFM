# Datos locales

El corpus persistente se almacenará en R2. Las copias de trabajo irán a
`local/`, `cache/`, `exports/` o `manual-inbox/`, todos ignorados por Git.
Estas carpetas se crearán cuando se necesiten; no hay documentos descargados.

No guardar PDFs, HTML, ZIP, datasets completos ni credenciales en Git.
Los ejemplos pequeños autorizados para pruebas irán a `tests/fixtures/`.
